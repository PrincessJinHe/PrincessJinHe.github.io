# 游侠客 · 长白山秋色6日徒步游 · 前端网页

轻奢自然治愈风的单页滚动官网，模块化分区、PC／平板／手机全端响应式，全程无弹窗、沉浸式阅览。

## 打开方式

直接双击 `index.html` 即可（无需服务器、无需联网，配图已本地化）。

## 文件结构

```
长白山/
├── index.html            页面结构（模块 1–4 全部内容）
└── assets/
    ├── styles.css        设计系统 + 全部样式（含响应式、打印、无障碍）
    ├── script.js         极简动效层（滚动渐入／导航状态／图片兜底）
    └── img/              长白山及吉林周边秋日实景照片
        ├── hero.png              首屏横幅（长白山远眺 · 金色落叶松林海）
        ├── d1–d6.*               行程 D1–D6 配图
        ├── gal-*.png             吉林省政府「吉林秋色」图集实景图
        ├── rev-02.png            天池航拍（用于五大秘境条）
        └── _unused/              暂未被页面引用的备用素材（可删）
```

## 设计令牌（改色只需改这里）

全部色值集中在 `assets/styles.css` 顶部的 `:root`：

| 变量 | 用途 |
|---|---|
| `--tea` / `--caramel` | 主色调：秋茶棕 / 焦糖暖橙 |
| `--mist` / `--lake` / `--forest` | 辅助色：雾松浅灰 / 天池浅蓝 / 森林墨绿 |
| `--bg` | 底色：米白柔色 |
| `--gold` | 强调色：低饱和暖金 |
| `--ink` ~ `--ink-4` | 正文 / 次要 / 标签四级文字 |

标题（粗体）、正文（常规、行高 1.9–2.1）、标签小字（浅灰细体）三级层级由 `--font-sans` 与字号 `clamp()` 统一控制。

## 替换配图

把新图片放进 `assets/img/`，然后在 `index.html` 中改对应 `src` 即可（例如首屏改 `assets/img/hero.png`）。

**关于首屏清晰度**：当前素材来自政府公开图库，最大边长 600px，宽屏全屏时略柔化——样式已用「极轻模糊 + 雾感渐变」把软化处理为高级雾感。若能提供游侠客自有实拍大图（建议宽 ≥ 1920px），替换后画面会明显更锐利。

## 动效与无障碍

- 仅有：滚动渐入、文字淡显、卡片悬浮微抬、首屏极缓位移、首屏横幅轻微视差
- 支持 `prefers-reduced-motion`：开启系统「减弱动效」后所有动画自动关闭
- 支持 `Ctrl + P` 打印：自动隐藏首屏大图与导航，直接导出 PDF
- 图片加载失败时自动降级为「秋色渐变 + 山形剪影」，不会出现破图
